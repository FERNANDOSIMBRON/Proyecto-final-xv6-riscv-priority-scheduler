# xv6 RISC-V - Priority Scheduler

## Trabajo Final

Implementación de un planificador de procesos por prioridades
en el sistema operativo xv6 para la arquitectura RISC-V.

## Objetivo

Modificar el planificador de procesos de xv6 para incorporar
un sistema de planificación basado en prioridades, permitiendo
evaluar y observar el comportamiento de los procesos.

## Estructura del proyecto

- kernel/: modificaciones del núcleo de xv6.
- user/: programas de usuario y pruebas del scheduler.
- documento_TrabajoFinal/: monografía, presentación y evidencias.

## Funcionalidades previstas

- Planificación por prioridades.
- Estadísticas de procesos.
- Comando ps para visualizar procesos.
- Pruebas del planificador.
- Evaluación del comportamiento de los procesos.

## Compilación y ejecución

Requisitos:
- GCC para RISC-V.
- QEMU.
- Make.

La compilación y ejecución se documentarán conforme
al entorno utilizado para xv6-riscv.
